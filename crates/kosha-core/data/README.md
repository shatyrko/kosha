`meters.tsv` comes from the `vidyut-chandas` crate (MIT, Ambuda project), which took it from
Shreevatsa Rajagopalan's *Sanskrit metres* project, sourced from Dr. Dhaval Patel's transcription
of the *Vṛttaratnākara*. It lists fixed (vṛtta) meters only; the anuṣṭubh śloka is checked by
Kosha's own rules (`src/sanskrit.rs`).
